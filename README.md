# Homelab SOC (Wazuh + VirtualBox)

This project documents my journey building a personal SOC (Security Operations Center) lab using VirtualBox and Ubuntu Server.

## Goals

- Learn how to deploy a SIEM (Wazuh)
- Understand logs, alerts, and detection
- Simulate attacks and analyze them
- Build hands-on experience for SOC Analyst roles

## Technologies

- VirtualBox
- Ubuntu Server 24.04
- Wazuh (SIEM)
- OpenSearch
- SSH
